# codemagic_demo

A Flutter app demonstrating how to use [Codemagic](https://codemagic.io/) to
release, patch, and distribute a Shorebird app with Android and iOS.

This app was created with `flutter create` and no changes have been made to its
source code, aside from updates to the theme color to validate that patches
were being applied.

Codemagic reads `codemagic.yaml` from the root of a repository, so to run these
workflows, copy this directory into a repository of its own.

See [https://docs.shorebird.dev/code-push/ci/codemagic/](https://docs.shorebird.dev/code-push/ci/codemagic/) for a detailed guide.

This sample used to live in
[shorebirdtech/codemagic_demo](https://github.com/shorebirdtech/codemagic_demo),
which is now archived.
